# Ленинградский Рогалик

Простой пошаговый RPG-рогалик на чистом HTML/CSS/JavaScript без внешних зависимостей. Работает в любом современном браузере — достаточно открыть `index.html`.

## Как запускать

1. Откройте каталог `html-rpg`.
2. Запустите файл `index.html` в браузере (двойным кликом или через меню «File → Open»).
3. Игра стартует автоматически. Управление полностью мышью.

## Особенности

- Процедурная генерация карты альтернативного Петербурга 2025 года, где победил Ленин-гриб.
- Перемещение по зонам кликами, отдельная сцена боя при встрече с врагами.
- Система навыков, инвентаря, предметов и прокачки персонажа.
- Диалоги с жителями «нижнего интернета» и события в локациях.
- Простые условия победы (победи Смольный Мицелий) и поражения (смерть без сохранения или окончание времени забега).
- Система костров: смерть откатывает к последнему сохранению.
- Ограничение забега по ходам, чтобы партия длилась до пяти минут.

Игра создана так, чтобы «просто работала» без установки дополнительных библиотек.
